# SpaceShip

A quick prototype of a physics-based arcade space game, made with Godot 4 (3D).

Fly a ship using thrust, pitch, yaw and roll, deal with planetary gravity and orbits, avoid asteroids and complete simple missions.

## Running

Open `project.godot` in Godot 4 and press Play. The main scene is `scenes/levels/game.tscn`.
